# Анастасия Задорина — психолог

Одностраничный сайт: консультации, рабочая тетрадь «Зависть», книжный и писательский клубы.

- `index.html` — вся страница (стили и скрипты внутри)
- `img/` — фотографии

Открыть локально: просто откройте `index.html` в браузере.
Опубликовать: Settings → Pages → Deploy from branch → `main` / root.

Кнопка «Что заполнить» в левом нижнем углу подсвечивает места, где нужны ваши данные (цены, образование, адрес, ссылки). Когда всё заполните — удалите кнопку `todo-toggle` из `index.html`.

## Яндекс Метрика

Счётчик подключается только после того, как посетитель нажал «Принять» в баннере о cookie. Номер счётчика (114174887) записан в `index.html` в строке `const YM_ID = ...`. Вебвизор выключен намеренно.
